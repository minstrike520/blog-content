> 注意：本篇以台文寫成。你可能會問：「台文是什麼？」簡單來說，台文是台語/台灣閩南語的書面形式。關於台文的一些常見問題，可參考[劉承賢先生撰寫的這篇文章](https://www.thenewslens.com/article/52927)。

我咧想：寫台文對我究竟有啥路用？

最近佇冊店有看著愈來愈濟用台語寫的冊。我若是有看著，攏會掀看覓。但是大部份用台語寫的題材我攏無興趣。寫啥物庄跤所在的故事，作者細漢的回憶，或者是我讀起來足無興趣的小說，著算講我足佮意「讀台文」，嘛袂想欲讀遮的冊。

敢講有欲讀台文的人攏是對「想欲保護台灣本土文化」開始的？敢無人是像我按呢，先對台文這豐富的文字系統吸引著，才開始了解台語的？

講到底，語言著是提來溝通的。若是這的上蓋基本的需求袂當滿足，一切攏免閣再講。

另外一件佮臺語文相關的代誌。

我實在是真佮意用 terminal 來寫台文。敢有人會捌我？ASCII 的美感佮羅馬字文的系統磕做伙。華語這个無羅馬字文傳統个，雖然硬欲寫嘛是會使，但是著欠一氣。（而且華語个音素較少，讀起來會較辛苦）

關於數字文，我上佮意个一點是：佇寫 code 个軟體內面，親像 Neovim，伊會自動推捒你佇彼个檔案寫个「單字」——注意，煞落來个才是重點：POJ 佮臺羅用「連字號」來標示多字詞，但是連字號前後無一定會予你个軟體看做是這个詞。所以這个特性干焦數字文才有！

以下是數字文的範例，內容是這个段落。規則真簡單：每一个字後面予伊个調號綴咧，本來寫連字號个所在直接磕做伙寫。

```
Goa2 sit8chai7 si7 chin1 ka3i3 iong7 terminal lai5 sia2 tai5bun5. Kam2 u7 lang5 e7 bat4 - goa2? ASCII e5 bi2kam2 kah4 lo5ma2ji7 bun5 e5 he7thong2 khap4 cho3hoe2. Hoa5gi2 chit8 e5 bo5 lo5ma2ji7 bun5 thoan5thong2 e5, sui1jian5 nge7 beh4 kong2 ma7si7 e7tang3 an2ne1 cho3, tan7si7 tioh8si7 kiam2 chit4 khui3. (Ji5chiann2 Hoa5gi2 e5 im1soo3 khah4 chio2, thak8 - khi2lai5 e7 khah4 sim1khoo2.)

Koan1i5 soo3ji7 bun5, goa2 siong7 ka3i3 e5 chit8 tiam2 si7: Ti7 sia2 code e5 nng2the2 lai7bin2, chhin1chhiunn7 neovim, i1 e7 chu7tong7 thui1sak4 li2 ti7 hit4 e5 tong2am7 sia2 - koe3 e5 "tan1ji7". Chhu3i3, soah4 - loh8lai5 e5 chit4 ku3 chiah4 si7 tiong7tiam2: POJ kah4 Tailo iong7 "lian5ji7ho7/dash" ("-") lai5 piau1si7 chit8e5 to1ji7su5, tan7si7 lian5ji7ho7 cheng5au7 bo5it4teng7 e7 hoo7 li2 e5 nng2the2 khoann3cho3 si7 chit4 e5 su5. Soo2i2 che1 tik4seng3 kan1na1 soo3ji7 bun5 chiah4 u7!
```

最大的問題是：應該，無人曉得按怎讀數字文。連我家己也是讀到真辛苦。而且有真濟人無佮意羅馬字，抑是毋知欲按怎讀。我本來就不是羅馬字派的，只是佮意數字文。

對於「無人欲看、無人看有」此個問題，[這篇 Threads 鋪文](https://www.threads.com/@wataro_ekhaucho3/post/DbgUnm6Ejle?xmt=AQG0tb7EeHTmoSI_zb_H5P35iXq2gyQx99LG8w7VwjqtC5xtxbvGopQZ89dJONpyyqG5zaIa&slof=1)反倒是會當參考：

> 若如此，有何物文體，會當用台語思考，又能使乎此偏心華語兮演算法看著兮。此個主意是我在咧台語聖詩用字當中尋著兮，其編者為著乎聖詩兮莊嚴感更加明顯，就將書面兮用字，拿來訓讀台語兮白話，下腳再寫白話字表示真正兮發音。頂面是乎人知意思，下腳乎人知欲如何唱。

伊提案用「訓讀字」來寫台文。伊在台語文的基督教「聖詩」尋著靈感，教會的人會用較文雅的字表示歌詩內底的口語。

我就在想，我也會使照此個方式在我的 blog 內底寫台文。也會當設一个自動翻譯的系統，予真正看無的人一个選擇。

此個 strategy 的目標是，寫到親像華語人在讀廣東話同款。雖然也是有人看著廣東書面文就哀講伊看無，但是若是較有耐心的總是會通。
